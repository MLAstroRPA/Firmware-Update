Wireless OTA Update (Alternative)

If your mount is already running and connected to your local network, you can update it wirelessly without a USB cable:

  1. Join your PC or smartphone to the mount's Wi-Fi (MLAstroRPA-XXXX) or access its assigned LAN IP.
  2. Open http://192.168.4.1 in your web browser.
  3. Navigate to 🛠️ CONFIG → 🚀 System Update.
  4. Click 🔍 CHECK FOR UPDATES and install over OTA.

USB Flashing Tips & Requirements

  • Supported Browsers: Google Chrome, Microsoft Edge, Opera, or Chromium on Windows, macOS, Linux, and ChromeOS. Safari and Firefox do not support Web Serial.
  • USB Cable: Use a high-quality data cable. Some cables only provide power and cannot carry USB Serial communication.
  • USB Driver: Ensure the Silicon Labs CP2102 USB-to-UART driver is installed if your computer does not automatically recognize the mount.
  • First-time / Recovery Flash: Check both bootloader.bin and partitions.bin alongside the firmware package to perform a full clean install.
  • Need help? Report an issue on GitHub or contact trong.minh@mlastro.com.
